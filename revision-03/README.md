# Fraser Coast — Concept 03

[Open Concept 03](https://lholmstrom-fcte.github.io/fraser-coast-mockup/revision-03/)

This folder contains an independent copy of the homepage mockup, updated from the CEO’s feedback.

The opening uses the supplied humpback photograph with a centred logo and large headline. Location labels identify the destinations in the imagery. A wongari feature, destination film placement and newsletter signup demonstration join the existing homepage sections.

All six navigation groups and the original seasonal data are retained. Our Ultimate Nature Calendar shows all twelve months. The map supports the three featured locations, zoom and pan.

The video placement awaits approved footage. Newsletter validation and confirmation run locally in the browser. The 45-second popup is a later step. Blog templates await reference research.
